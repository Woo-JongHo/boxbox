# 줄 폭 기준 — "가로 스크롤 없이 보인다"

상태: 측정 대기 · 날짜: 2026-09-30 · 계획: M1.8 S4

## 기준

120이라는 고정 숫자 대신, **기준 환경에서 가로 스크롤 없이 보이는 칸 수**를 줄 폭의 근거로 삼는다. 숫자는 이 기준의 결과이고, 약속(3층)의 기본값이다. 사용자는 `.xxx/config.json`에서 바꿀 수 있다. 헌장의 불변식이 아니다.

**기준 환경 (2026-09-30 결정):** 13–14인치 노트북 기본 배율 + VS Code 기본 설정(글꼴 14px, 탭 4칸) + 사이드바 열림. 좁은 쪽에 맞추면 넓은 화면에서도 스크롤이 생기지 않는다.

## 두 개의 선

"넘으면 바로 내린다"가 아니라 허용 구간을 둔다.

| 구간 | 동작 |
|---|---|
| 폭 ≤ 권장선 (soft) | 아무것도 하지 않는다 |
| 권장선 < 폭 ≤ 한계선 (hard) | 허용한다. 폭만 보고하고, 단순화나 줄바꿈은 제안(SUGGEST)만 한다 |
| 폭 > 한계선 | 가로 스크롤이 생긴다. 넘는 행만 세로형으로 바꾸거나(이미 import와 선언 표에 있는 방식), 나누기를 제안한다 |

- **한계선 = 기준 환경의 측정값**(스크롤이 생기기 직전 칸). **권장선 = 한계선 − 여유분**. 여유분은 측정 후 정한다.
- 판단은 **한 줄로 썼을 때의 폭**으로만 한다. 이미 세로형인지 아닌지에 따라 기준을 바꾸지 않는다(같은 토큰에 정본이 하나만 있어야 멱등과 결정성이 지켜진다).
- 폭은 표시 폭으로 센다. CJK는 2칸, 탭은 편집기 탭 폭이다(`common/display-width.ts`).

## 여러 축으로 판단한다 (2026-09-30)

숫자 하나로 자르면 애매하다. 짧은 항목 11개를 나열한 150칸 줄은 읽기 쉽고, 조건이 세 겹 중첩된 100칸 줄은 읽기 어렵다. 그래서 폭은 여러 축의 값으로 보고한다.

| 축 | 재는 것 | 기준의 성격 | 리포트 |
|---|---|---|---|
| ① 화면 | 가로 스크롤이 생기는가 | 실측(유일한 절대 기준) | A1, A2 |
| ② 비교 | 같은 표의 다른 행보다 튀는가 | 상대(두 번째로 긴 행과의 차) | A3 |
| ③ 밀도 | 한 줄의 열·항목·중첩 수 | 개수 | A1에 함께 표시 (열 수) |
| ④ 공백 낭비 | 정렬 공백 ÷ 내용 글자 | 비율 | A7 |
| ⑤ 문형 | 나열(`LIST`, `MAP`, `IMPORT`)인가 로직(`WHEN`, `DO`)인가 | 문형별 허용 폭 | A1에 함께 표시 |
| ⑥ 프로젝트 분포 | 이 레포에서 평소 이 정도 길이인가 | 레포 자신의 분포 | 아직 없음 |

자동으로 바꾸는 것은 ① 화면 축뿐이다. 나머지는 알람으로 값을 보여주고, AI 확인과 사람의 판정이 쌓이면 축별 기준이 데이터로 정해진다.

## 계산식과 추정

```
보이는 칸 수 = (화면 폭 − 편집기 UI 폭) ÷ 한 칸의 폭
```

- 화면 폭은 OS 배율을 적용한 값이다(1920×1080 @125% → 1536). StatCounter 2026-08 데스크톱: 1920×1080 22.2%, 1536×864 6.7%, 1366×768 5.2% (웹 방문자 기준이라 개발자 분포와 다를 수 있다).
- 한 칸의 폭: VS Code 기본 14px. Windows Consolas 0.55em → 7.7px, macOS Menlo 0.60em → 8.4px.
- 편집기 UI 폭 (추정): 활동 막대 48 + 사이드바 300 + 줄 번호 60 + 미니맵 100 + 스크롤바 14 ≈ 520px (사이드바 닫힘 ≈ 220px).

| 환경 | 사이드바 열림 | 사이드바 닫힘 |
|---|---|---|
| 1920 데스크톱 (Windows) | 약 181 | 약 220 |
| 1536 노트북 (Windows 125%) | 약 131 | 약 171 |
| MacBook Pro 14 (1512) | 약 118 | 약 153 |
| MacBook Air 13 (1470) | 약 112 | 약 148 |
| 1366 노트북 | 약 109 | 약 149 |

추정치다. UI 폭은 측정값으로 바꾼다.
