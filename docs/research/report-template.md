# 평가 보고서 양식 (REPORT)

`docs/paper/eval-methodology.md` 9절 보고 목록을 채우는 형식이다. 파일럿·본시험(주/안정성)·정책 실험 모두 이 양식으로 쓰고, 한 실험당 파일 하나로 남긴다.

## 파일 규칙

- **위치와 이름:** `docs/research/reports/YYYY-MM-DD-<단계>.md` — 단계는 `pilot` | `main` | `stability` | `policy`.
- **전달 방식:** 결론이 0절(한 줄 결론)과 1절(적격 판정표)로 맨 앞에 온다. 보고할 때는 이 두 절을 요약해 보여 주고, 전문은 파일로 남긴다.
- **채우는 규칙:**
  - 빈 칸을 남기지 않는다. 측정하지 못한 것은 `측정 못함 — 사유`로 적는다. 해당 단계에서 하지 않는 점검은 `해당 없음`으로 적는다.
  - 측정값과 해석을 섞지 않는다. 해석은 각 점검의 `읽음` 칸에만 적는다.
  - 수치는 결정적 채점 코드가 매니페스트·원시 기록에서 뽑은 값 그대로 적는다(공준 5). 조정 세션이 눈으로 판단해 고친 수치가 있어서는 안 된다.
  - 사전 등록 이후 바뀐 것이 하나라도 있으면 7절에 반드시 적는다.
